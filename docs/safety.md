# 数字研发与物理操作边界

P0 只执行本地参数建模与文件导出，无 USB、串口、烧录、设备供电、电机控制、网络服务监听或制造下单接口。

- 不接受调用方 Python 源码、shell 命令和任意输出路径。
- 参数限制为有限毫米尺寸；壁厚和间距检查只保证所建模板的基本几何关系。
- 根目录由服务器配置，构建 ID 与文件白名单由服务校验，拒绝符号链接和越界路径。
- 工作进程超时返回失败，未完成目录不可作为成功交付。文件哈希用于发现变更，不是数字签名。
- 不保证 OS 级隔离或防御拥有同一文件系统写权限的恶意用户；多租户、配额与联网部署不在 P0 范围。
- 几何有效、STEP 可回读或 STL 水密，不等于结构强度、打印质量、电气安全或实物适配。
- 只有用户提供真实测量值才可标记 `user_measured`，说明测量依据；工具不会替用户验证测量真实性。

后续接入固件和硬件测试时，默认只允许编译和只读采集。烧录、通电、电机动作、生产下单或其他危险实际操作必须在动作发生前获得人工明确确认，并记录操作对象和范围。
