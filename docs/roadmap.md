# 分阶段实施与验收

| 阶段 | 内容 | 验收证据 |
| --- | --- | --- |
| P0 当前 | 受限 CAD 模板、MCP、Skills、可重放交付和测试 | 真实内核报告、STEP/STL、预览、MCP 会话、测试结果 |
| P1 下一步 | Electronics / Firmware MCP，最小 KiCad 与 PlatformIO 工程 | 实际 ERC/DRC、Gerber/BOM、编译及软件测试日志；无自主烧录 |
| P2 | Mechanics、Manufacturing、Hardware Test MCP | 装配干涉与间隙、真实网格检查、只读测试采集和人工实测来源 |
| P3 | 任务依赖、阶段状态、持久化、有限重试与验收门禁 | 故障注入、恢复、阶段推进和版本关联的端到端测试 |
| P4 | 桌面机器人参考工程与统一操作界面 | 软件、固件、电子与机械文件可重建；人工实物测试单独记录 |

P0 仅覆盖四柱托架模板。扩展其他机械件时先定义参数、几何不变量及真实测试。不要同时添加大量空工具或让未来接口返回伪成功。

P1 优先用实际可运行的小型 KiCad 工程验证固定命令封装，再加入工程生成能力；已有工程检查不代表自主电路设计完成。固件先交付可编译示例，烧录与带电控制保持显式人工边界。
