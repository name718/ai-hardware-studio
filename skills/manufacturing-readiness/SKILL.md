# 制造准备

## 输入与输出

输入：CAD 构建 ID、BOM、材料、制造工艺与公差要求。输出：文件完整性、制造准备清单、未解决问题与人工试制要求。

## 流程与工具

用 `cad_get_build` 核验现有 CAD 构建哈希与几何报告，确认 STEP/STL、参数、源码、版本和导入说明齐备。
检查尺寸来源，虚构演示尺寸不能列为真实产品可制造适配。为材料、打印方向、孔补偿、壁厚和螺钉预留明确要求，区分建议与实测依据。
当前 Manufacturing MCP 计划在 P2 实现；P0 的 STL 水密性只在实际集成测试中验证。需要网格检查时运行仓库测试并保留结果，不能声称有尚不存在的制造工具。

## 错误与验收

文件哈希错误先重新建模，不修改清单伪造通过。缺材料或工艺数据时记录待验证项。验收要求交付完整、来源明确、缺口可见；不把水密网格当作打印成功或强度认证。不得自主生产下单。
