# 电子与固件

## 输入与输出

输入：功能、器件资料、连接关系、电源与接口约束。输出：电气接口、工程方案、BOM、固件协议和实际验证日志或明确的能力缺口。

## 流程与工具

先确认 MCU、电源预算、电平、连接器、负载与控制接口。使用真实 datasheet 核对引脚与限制。
检查 MCP 工具列表。当前仓库 Electronics / Firmware MCP 位于 P1，尚未实现；不得调用想象中的工具或伪造 ERC/DRC、编译成功。
工具可用后才使用固定命令、受限工程目录运行 KiCad 检查与固件编译，保留版本、退出码和日志。PCB 外形、孔距等机械依赖可通过现有 CAD Schema 传入四柱托架流程；无真实尺寸时保持演示标记。

## 错误与验收

缺少 KiCad、ESP-IDF 或 PlatformIO 时报告未运行；错误应由实际日志定位并有限修复。ERC/DRC 不代表电气安全认证，编译不代表真实硬件可用。无事前明确人工确认，不烧录、不通电、不执行电机动作。
