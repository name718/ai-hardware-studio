# 物理反馈闭环

## 输入与输出

输入：原始构建 ID、人工测量值、照片与日志及测量条件。输出：问题记录、参数变更依据、新构建 ID、数字回归报告和剩余实测计划。

## 流程与调用

1. 用 `cad_get_build` 读取原构建，确认人工反馈对应版本，记录测量单位、误差和环境。
2. 区分实际测量、用户观察与工程推断；照片不能自动提供精密尺寸。
3. 有测量依据时更新参数，用 `dimension_source: user_measured`、`source_note` 和逐项 `dimension_evidence` 记录名义值、误差、来源、定位与版本。全部尺寸显式填写，设计选择与实测分开；测量误差未知时不能填零冒充准确。调用 `cad_assess_parameters`，再建模和回读重新验证。
4. 对比新旧参数和检查结果，保留原始证据，列出仍需人工检查的配合、接口和装配项目。

## 错误与验收

Hardware Test MCP 尚未实现，不声称自动获取了 USB、串口或仪器数据。数据缺失或矛盾时报告不能确认的结论，继续可独立完成的数字工作。验收需具备版本关联、变更依据与实际回归结果；任何危险硬件动作均需另行明确人工确认。
